S9 · REFERENCE APPENDIX — curriculum, invariants, direction, release scope

CURRICULUM CHAINS — prerequisite order + misconceptionsLearn walks chains in this order; each step names the trap it defuses
CHAINS
ARRAYS→MAPS
running-sum → pivot → two-sum → contains-duplicate → valid-parentheses → longest-substring. Traps: values-instead-of-indices · check-after-insert reuses the element · empty-map is a valid state.
TREES DFS→BFS
inorder → pre/postorder → max-depth → level-order. Traps: visit-on-push vs visit-on-pop · depth vs level index · storage order ≠ visit order.
CHAINS, CONTINUED
GRIDS (ISLANDS)
number-of-islands → max-area-of-island. Traps: mark-visited-on-enqueue · 4-directional only · count vs measure.
DP 1D→2D
fibonacci → climbing-stairs → house-robber → counting-bits → LCS → edit-distance. Traps: dependency arrows + answer cell in 2D.
FAMILY INVARIANTS — what each picture must make visibleA frame without its invariant state fails review. No invented geometry.
INVARIANTS 1/2
dp-2d: cell(i,j)=f(two cells read) — grid + dependency arrows + answer badge. dp-1d: dp[i]=f(dp[i-1],dp[i-2]) — value row + previous one/two pointers. graph-bfs: frontier is the visited/unvisited boundary; distance = level. graph-dfs: stack = current path; pop = backtrack. backtracking: choose→explore→un-choose as a tree path; pruned branches dimmed.
INVARIANTS 2/2
sliding-window: window [l,r] satisfies a count invariant — char-count table + window band. monotonic-stack: monotone candidates; a pop resolves the popped element. intervals: merged blocks grow while next.start ≤ current.end — 1-D timeline. heap: parent ≥ children; top-k = heap of size k. union-find: find(x) = root; compression flattens.
