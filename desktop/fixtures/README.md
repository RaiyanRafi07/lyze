# Native desktop reference fixtures

`native-baseline.json` (v1) is the original development fixture for the native editor, diagram, and learning-engine port. Two Sum exercises the array walkthrough. Number of Islands exercises a grid-based graph traversal with more frames and state changes.

`catalog-extra.json` (v2, generated by `export-all.mjs`) covers all 150 lessons: captured walkthrough frames plus deterministic practice variants (three per lesson where the engine defines them, each with two hints). Lessons without an engine walkthrough adapter carry `walkthrough: null`, and the desktop overlays in `desktop/lessons/v1/` pin adapter-format inputs under a `walkthrough` block so the export replays them. Every walkthrough frame maps to reference code lines, and every variant carries judge-ready tests.

The exporters read the public lesson records through the checked-in index and call the current walkthrough and practice builders. The first existing judge case supplies input literals and expected output. Each fixture identifies its record and engines, and retains the generated walkthrough and variant payloads intact for comparisons. The root `version` describes this fixture envelope only.

Run from the repository root.

```powershell
node desktop/fixtures/export-baseline.mjs --check
node desktop/fixtures/export-all.mjs --check
```

After reviewing an intentional engine or data change, regenerate with `node desktop/fixtures/export-all.mjs` (or `export-baseline.mjs` for the v1 pair) and review the JSON diff. The checks also report per-kind walkthrough coverage and the variant count. Java and C++ compile and execution checks belong to the judge suites. Node is needed for generating and checking these development fixtures.
