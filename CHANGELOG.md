# Changelog

## v0.1.2 — first public build

First thing you can actually download and run. Windows x64 portable, fully offline.

- 2,913 problems offline, Java + C++ judged locally for real
- 150 NeetCode walkthroughs with step frames + 3 practice drills each
- 16 themes + VS Code theme import, trace view, local progress/drafts
- 134/134 judge parity, headless gate green

Install: unzip anywhere **without spaces in the path** (e.g. `C:\Lyze`), run `LeetCodeLab/leetlab-app.exe`. First launch creates `%LOCALAPPDATA%\LeetCodeLab`.
